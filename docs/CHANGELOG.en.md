# Release notes

## 3.7.4.3

- DATs retain UXBA processing history. Loading a saved DAT displays conversion, anonymization, and battle extraction operations with their UXBA versions. The marker survives renaming and ZIP packaging.
- Includes the fix for restoring enemy and encounter-object spawn/despawn states when extracting later battle intervals.
- Anonymization changes supported home-world information as well as names and character identifiers for sharing.

Close the app before updating, then extract the new ZIP into a separate folder. Keep all bundled folders together and retain your original DATs.
