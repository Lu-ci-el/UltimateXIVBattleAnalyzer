## 3.7.5.9

Extraction now retains the original recording's initial entry time. Output filenames include the applied recorder, anonymization settings, and extraction tag. Full anonymization adds six outfits and supports removing headgear for every race and gender. Armor colors cover all 32 combat classes and jobs, including Blue Mage and Beastmaster. Weapons and shields are undyed.

## 3.7.5.8

Fixed battle extraction failures caused by missing player state when participants despawned or spawned again before the selected battle.

## 3.7.5.7

Fixed batch conversion button visibility and dictionary selection for each conversion operation. Separate remembered folders, subfolder processing, and skip reasons remain available.

## 3.7.5.6 — Initial public release

Inspect DATs, extract battles, anonymize replays, change the recorder, convert supported generations, extract matching ACT logs, and archive recordings as individual ZIPs. See the [user guide](USER_GUIDE.en.md) for setup and saving instructions.

For a first installation, extract the entire download ZIP into a new folder. Keep original DATs and save processed results separately.
