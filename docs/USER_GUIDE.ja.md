# UXBA 操作ガイド

[トップへ](../README.md) · [English](USER_GUIDE.en.md)

## 起動の準備

配布ZIPをフォルダごと展開し、`UltimateXIVBattleAnalyzer.exe`を起動します。ZIPの中から直接起動せず、`Runtime`、`Resources`、`Settings`も一緒に配置してください。同梱の辞書を移動・削除する必要はありません。

起動時に必要と表示された場合は [.NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) と [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) を導入します。書き込み可能なフォルダで使ってください。

元DATを保管し、編集結果は別ファイルへ保存してください。設定はアプリの`Settings`フォルダ、作業用ファイルは`Work`フォルダに保存されます。入力・保存先は操作時に選びます。

## 1. DATを開く

![メイン画面](images/main-ja.png)

1. 「DAT読み込み」を押し、DATまたは対応するZIPを選びます。
2. 上部の録画情報、プレイヤー一覧、戦闘一覧を確認します。
3. 戦闘一覧で開始・終了、時間、結果、敵などを確認します。横に収まらない列はスクロールして見られます。

右上で日本語・英語を切り替えられます。「状態リセット」で現在の選択をリセットできます。読み込み・変換・匿名化にはそれぞれ対応条件があり、読み込めるDATがすべて編集できるわけではありません。

記録内容から名前を特定できない場合は、匿名化をOFFにしてもPlayer番号で表示されます。人物を識別できない行は記録者として選べません。

## 2. 戦闘区間を取り出す

現代DATが対象です。対応する過去DATは、先に「過去→現代」で変換します。

1. DATを開き、戦闘一覧から取り出したい区間を選びます。
2. 「保存」を押し、区間抽出の確認内容を確認します。
3. 保存先とDAT／ZIPを選び、保存します。

戦闘行を選ばずに保存すると、録画全体が対象になります。抽出と匿名化を同時に行う場合は、保存前に匿名化を設定します。匿名化済みDATからの追加抽出はできないため、元DATからやり直してください。

抽出後の初突入時刻は、元DATの初突入時刻を保ちます。ダンジョンにかかわらず同じ時刻へ固定することはありません。

## 3. 名前を匿名化する

1. 対応する現代DATを開きます。
2. 「プレイヤー名を匿名化する」を有効にします。
3. 録画全体を保存するなら戦闘行を選ばず、1戦だけ取り出すならその行を選びます。
4. 「保存」を押し、別のファイルへ出力します。

DAT内の名前は `Paladin`、`White Mage` など、各人物の正式な英語ジョブ名に変わります。画面では `Player 01`、`Player 02` のように表示します。同じジョブの人物も番号で区別できます。

対応するキャラクター識別情報と所属サーバー情報も変更し、内部の撮影日時を固定値へ置き換えます。外見は変わりません。元のファイル名に名前や日時が含まれる場合は、共有するファイル名も確認してください。

## 4. 完全匿名化で見た目も変える

![完全匿名化の設定](images/anonymous-ja.jpg)

1. 匿名化前の現代DATを開き、「完全匿名化」を押します。
2. 「完全匿名化 ON」を有効にします。
3. 種族・性別、身長、着ぐるみを設定します。すべての種族・性別で頭装備を外せます。
4. 設定画面を閉じ、「プレイヤー名を匿名化する」が有効な状態で保存します。

頭装備を外す場合は、選んだ種族の標準顔に揃え、髪型を人物ごとにランダムにします。ルガディンはハゲになります。染色できる防具は、通常クラス・青魔道士・魔獣使いを含む32種類の指定色に変わります。染色できない防具は元の色を保ち、武器と盾は無染色になります。武器はIL665のRE+系、青魔道士はジェントルメイジ・アンブレラRE+、魔獣使いはビーストリージュ・ハンドアクス／ホプロンを使います。フェニックスヒーロー、ヴァンガード、ヨルハ五一式・五三式・五五式、二号B型も選べます。

設定しただけでは元DATは変わりません。保存時に名前・識別情報・見た目を変更し、記録者のジョブゲージデータも消去します。

「完全匿名化」でも、ジョブ構成や動き、攻略方法から人物を推測できる場合があります。共有前に保存結果を確認してください。

## 5. 記録者を変更する

1. 対象DATを開き、「記録者を変更する」を有効にします。
2. 表示されたパーティメンバーから1人を選びます。
3. 「保存」で別ファイルに出力します。

匿名化と同時に記録者を変更できます。匿名化済みDATを読み直して、別の記録者へ変更することもできます。同じジョブの候補が複数いる場合は、Player番号で選び分けてください。

匿名化済みDATを開くと、名前の匿名化・完全匿名化・戦闘区間抽出・キャラID変更・過去→現代変換は利用できません。録画情報や戦闘一覧は確認でき、記録者変更を有効にすると保存できます。別の加工をしたい場合は元DATを開いてください。

### 保存時のファイル名

元の名前の後ろに、実行した操作の目印が付きます。例：`録画名 T1 Miqo(M) S RB Split.dat`。

- `T1`・`T2`・`H1`・`D1`など：変更先の記録者。画面の表示と同じです。
- `Miqo(M)`：種族の略称と性別（M＝男性、F＝女性）。
- `S`・`M`・`L`：身長（最小・中間・最大）。
- `RB`など：着ぐるみの略称。
- `Split`：戦闘区間抽出。名前だけの匿名化には`Anon`が付きます。

種族略称：Hyur、Ele、Lala、Miqo、Roe、AuRa、Hroth、Viera。

着ぐるみ略称：ウサギRB、ウサギ別衣装RD、チョコボCB、ニワトリCK、トンベリTB、カッパKP、カエルFG、ブタPG、ゾウEL、トナカイRE、魔法少女MG、フェニックスヒーローPH、ヴァンガードVG、ヨルハ五一式Y51、二号B型2B、ヨルハ五三式Y53、ヨルハ五五式Y55。

## 6. 過去のDATを現代へ変換する

「過去→現代」を押し、対象の過去DATを選んで、画面の案内に従って別ファイルへ保存します。変換後のDATを開くと、現代DAT向けの操作へ進めます。

対応状況は録画の世代と記録内容によって異なります。UXBAで加工したDATではなく、元の録画を使用してください。未対応と表示された場合は、エラー文を控えてください。

### フォルダ内をまとめて変換する

1. 「過去→現代」の右にある「過去一括変換」を押します。
2. 入力フォルダを選び、続いて別の出力フォルダを選びます。それぞれ前回の場所を記憶します。
3. サブフォルダ内のDATも対象になります。変換結果は元のフォルダ構成を保って出力します。
4. 完了画面で成功・スキップ件数と各ファイルの理由を確認します。

未対応のDAT、現代DAT、加工済みDAT、同名の出力がある場合はスキップします。元DATと既存の出力は上書きしません。処理中は「中止」で止められ、完了済みの出力は残ります。入力・出力には互いに重ならない別々のフォルダを選んでください。

## 7. キャラIDを変更する

自分以外が記録したDATのPT表示を整えるための機能です。参照用として、自分のキャラクターを記録したDATを用意します。

1. 変更対象のDATを開き、「キャラID変更」を押します。
2. 参照する自分のDATを選びます。
3. 保存先を選び、別名で保存します。標準のファイル名は `CHARACTER_ID_` で始まります。

参照DATと対象DATを取り違えないようにしてください。匿名化済みDATでは使えません。パーティメンバーから記録者を選びたい場合は、前項の「記録者変更」を使います。

## 8. 対応するACTログを取り出す

録画したときのACTログが必要です。DATからACTログを新しく生成する機能ではありません。

1. 「DAT→ACTログ検索→正式Split」を押します。
2. 対象の元DATを選びます。
3. ACTログを保管しているフォルダを選びます。サブフォルダや対応するログZIPも検索対象です。
4. 出力先を選び、完了後のログを確認します。
5. FF Logsに掲載する場合は、FF Logsのアップローダーを使用します。

照合には録画日時を使うため、匿名化前の元DATを使ってください。DATの匿名化はACTログには適用されません。ログの公開範囲はFF Logs側でも確認してください。

## 9. 過去DATを個別ZIPに整理する

1. 「個別ZIP圧縮」を押します。
2. 元DATの入力フォルダを選びます。
3. 保存先として別のフォルダを選びます。入力フォルダ自身や、その内側・上位のフォルダは使えません。
4. 確認して実行します。対象DATは1本ずつZIPになり、世代やコンテンツなどで分類されます。

元DATは変更・移動されません。現代世代は対象から除かれ、対応する過去の録画を整理します。同じ内容のZIPは再作成を省き、同名で異なる内容は別名で保存します。圧縮によって匿名化はされません。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 起動しない | ZIP全体を展開したか、必要なランタイムが入っているか確認します。 |
| 辞書を読み込めない | 同梱の `Settings/DictionaryPacks/DictionaryPack.uxdic` を含めて展開し直します。 |
| 保存や匿名化が使えない | 対応する現代DATか、匿名化済みDATではないか、画面の案内を確認します。 |
| 変換・抽出で止まる | 対応外の世代・記録内容の可能性があります。表示されたエラー文を控えます。 |
| ACTログが見つからない | 匿名化前の元DATと、録画時のACTログを指定したか確認します。 |

フルリメイクは開発中で、配布版では案内を表示します。

[不具合報告](https://github.com/Lu-ci-el/UltimateXIVBattleAnalyzer/issues/new/choose)には、アプリの版・操作手順・期待した結果・実際の結果・エラー文を添えてください。DATやACTログは公開投稿に添付せず、画像の個人情報も隠してください。[開発支援について](SUPPORT.ja.md)
