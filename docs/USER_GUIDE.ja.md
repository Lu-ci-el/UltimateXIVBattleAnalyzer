# UXBA 操作ガイド

[トップへ](../README.md) · [English](USER_GUIDE.en.md)

## はじめに

配布ZIPをフォルダごと展開し、`UltimateXIVBattleAnalyzer.exe`を起動します。同梱のフォルダ・ファイルはそのまま使ってください。必要と表示された場合は [.NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) と [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) を導入します。

元のDATを保管し、加工結果は別ファイルへ保存してください。操作できる項目はDATの種類や状態によって変わります。

## DATを開く・保存する

1. 「DAT読み込み」でDAT、またはDATを1本含むZIPを選びます。
2. 録画情報・プレイヤー一覧・戦闘一覧を確認します。
3. 必要な操作を設定し、「保存」でDATまたはZIPへ出力します。

戦闘行を選ばずに保存すると録画全体が対象になります。右上で日本語・英語を切り替えられます。

## 戦闘区間を取り出す

1. 現代DATを開き、戦闘一覧から取り出す区間を選びます。
2. 「保存」を押し、確認画面の内容を確認します。
3. 保存先とDAT／ZIPを選びます。

過去DATは、対応していれば先に「過去→現代」で変換します。匿名化済みDATからの追加抽出はできません。抽出と匿名化を一緒に行う場合は、元DATで両方を設定して保存します。

## 名前を匿名化する

1. 匿名化前の現代DATを開きます。
2. 「プレイヤー名を匿名化する」を有効にします。
3. 「保存」で別ファイルへ出力します。

名前は英語のジョブ名へ変わり、画面では`Player 01`のような番号で表示します。キャラクター・所属サーバーの識別情報と撮影日時も変更します。外見は変わりません。タンクを1番目にします。

## 完全匿名化で見た目も変える

1. 匿名化前の現代DATを開き、「完全匿名化」を押します。
2. 「完全匿名化 ON」を有効にします。
3. 種族・性別・身長・衣装・頭装備を設定します。
4. 設定画面を閉じ、名前の匿名化も有効にして保存します。

名前と見た目をまとめて変更します。頭装備を外すと標準の顔と人物ごとに異なる髪型になり、ルガディンは髪なしになります。染色できる防具はクラス・ジョブ別の色になり、武器と盾は無染色になります。録画途中の装備変更にも設定を適用します。

設定を選んだだけでは元DATは変わりません。匿名化した後に設定を変えたい場合は、元DATからやり直してください。

## 過去のDATを変換する

「過去→現代」を押して元の過去DATを選び、画面の案内に従って別ファイルへ保存します。変換後のDATを開くと、抽出や匿名化を行えます。

まとめて変換する場合は「過去一括変換」を使います。

1. 入力フォルダと、別の出力フォルダを選びます。
2. サブフォルダも含めて変換します。出力先には元のフォルダ構成を保ちます。
3. 完了画面で成功・スキップ件数と理由を確認します。

未対応・現代・加工済みのDATや、同名の出力がある場合はスキップします。元DATと既存の出力は上書きしません。「中止」で止めても完了済みの出力は残ります。

## キャラIDを変更する

自分以外が記録したDATを自分のキャラクターに合わせる機能です。参照用に、自分のキャラクターを記録したDATを用意します。

1. 変更するDATを開き、「キャラID変更」を押します。
2. 参照用の自分のDATを選びます。
3. 保存先を選び、別名で保存します。

参照用と変更対象のDATを取り違えないようにしてください。

## 対応するACTログを取り出す

録画時のACTログを用意します。DATから新しいACTログを作る機能ではありません。

1. 「DAT→ACTログ検索→正式Split」を押します。
2. 匿名化前の元DATを選びます。
3. ACTログのフォルダを選びます。サブフォルダや対応するログZIPも検索します。
4. 出力先を選び、取り出されたログを確認します。

FF Logsへ掲載する場合は、FF Logsのアップローダーを使います。DATの匿名化はACTログには適用されません。

## 過去DATを個別ZIPに整理する

「個別ZIP圧縮」で入力フォルダと別の出力フォルダを選ぶと、対応する過去DATを1本ずつZIPにし、世代やコンテンツで分類します。

元DATは残ります。現代DATは対象外です。同じ内容のZIPは作成を省き、同名で内容が異なる場合は別名で保存します。ZIP圧縮だけでは匿名化されません。

## 保存名の目印

実行した操作に応じて、元のファイル名の先頭に目印が付きます。

| 目印 | 意味 |
| --- | --- |
| `T1` | 先頭のタンク |
| `Miqo(M)`など | 種族と性別（M＝男性、F＝女性） |
| `S`・`M`・`L` | 身長 |
| `RB`など | 衣装 |
| `Head(on)`・`Head(off)` | 頭装備あり・なし |
| `Anon` | 名前の匿名化 |
| `Split` | 戦闘区間の抽出 |

## 困ったとき・不具合報告

起動しない場合は、ZIP全体を展開したか、必要なランタイムが入っているか確認してください。辞書のエラーが出る場合は、同梱ファイルを含めて展開し直してください。

[不具合報告](https://github.com/Lu-ci-el/UltimateXIVBattleAnalyzer/issues/new/choose)には、アプリのバージョン・行った操作・症状・エラー文を記載してください。変換などがうまくいかないDATは、[Dropboxの提出窓口](https://www.dropbox.com/request/gkofh48datowq9uozjif)へ元DATと説明を送ってください。Issueがある場合はURLも添えてください。
