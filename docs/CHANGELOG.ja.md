# 公開版の案内

[トップへ](../README.md) · [操作ガイド](USER_GUIDE.ja.md) · [English](CHANGELOG.en.md)

## 3.7.5.8

戦闘区間の抽出で、参加者の再登場・退場によって必要な情報が欠け、抽出できなくなる問題を修正しました。

## 3.7.5.7

一括変換ボタンの表示と、変換処理ごとの辞書選択を修正しました。入力・出力フォルダの記憶、サブフォルダの処理、スキップ理由の表示を引き続き利用できます。

## 3.7.5.6 — 初公開版

DATの確認、戦闘区間の抽出、匿名化、記録者変更、対応世代の変換・フォルダ一括変換、ACTログの抽出、個別ZIP圧縮を利用できます。導入から保存までの手順は[操作ガイド](USER_GUIDE.ja.md)をご覧ください。

初めて使う場合は、配布ZIP全体を新しいフォルダへ展開してください。元DATは保管し、加工結果を別ファイルへ保存してください。
