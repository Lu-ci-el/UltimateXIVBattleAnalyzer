# 開発を支えてください

[トップへ](../README.md) · [English](SUPPORT.en.md)

UXBAは、リプレイを整理したり、見返したい戦闘を取り出したり、共有前に匿名化したりするために作っています。

開発には継続的な費用がかかり、ゲームの更新に合わせた調整や、世代ごとのデータ確認にも時間が必要です。自費で更新を続けられる見込みは2026年12月までです。2027年1月以降の更新や8.0対応、開発中のフルリメイクをどこまで進められるかは、皆さんからの支援にかかっています。

使って便利だと感じたら、無理のない範囲で応援してもらえると助かります。応援のメッセージも励みになります。

- [Ko-fiで支援する](https://ko-fi.com/lost2)
- [OFUSEで支援する](https://ofuse.me/lost)

不具合報告や機能の相談は、リポジトリのIssues・Discussionsへお願いします。
