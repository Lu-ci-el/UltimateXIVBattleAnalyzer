# UltimateXIVBattleAnalyzer

[3.7.4.3をダウンロード](https://github.com/Lu-ci-el/UltimateXIVBattleAnalyzer/releases/tag/v3.7.4.3) · [更新内容](docs/CHANGELOG.ja.md)

[English](README.en.md) · [画像付き操作ガイド](docs/USER_GUIDE.ja.md) · [開発支援](docs/SUPPORT.ja.md)

FFXIVのリプレイDATから戦闘一覧やパーティ構成を確認し、戦闘区間の取り出し、匿名化、対応するACTログの抽出まで行えるWindows用アプリです。

![UXBAのメイン画面](docs/images/main-ja.jpg)

## できること

| 機能 | 使いどころ |

| --- | --- |

| DATの読み込み | 対応する各世代のDATからコンテンツ、戦闘一覧、時間、パーティ構成などを表示します。 |

| ACTログの検索・Split抽出 | DATとACTログの保存フォルダを選び、録画に対応するログを取り出します。FF Logsへアップロードするログの準備に使えます。 |

| 名前の匿名化 | 現代DATの名前を `Player 01` などへ変更します。キャラクターの識別ID、所属サーバー情報、内部の撮影日時も共有用に変更して保存します。 |

| 完全匿名化 | 名前などの匿名化に加え、種族・性別・身長・衣装を設定して見た目を変更します。 |

| 戦闘区間の抽出 | 戦闘一覧から取り出せる区間を選び、別のDATまたはZIPに保存します。 |

| 過去→現代変換 | 対応する過去世代のDATを、アプリが扱う現代世代へ変換します。対応状況はDATの世代によって異なります。 |

| キャラID変更 | 自分のDATを参照して対象DATのキャラIDを変更し、PT一覧の抜けなど、リプレイの表示を整えます。 |
| 個別ZIP圧縮 | 対応する過去のDATを1本ずつZIPにして別フォルダへ整理します。元DATは残ります。 |

フルリメイクは開発中です。今後の開発は支援状況を見ながら進めます。

3.7.4.3から、保存したDATを開くと変換・匿名化・戦闘区間抽出の履歴と処理したUXBAの版を確認できます。[識別印の見方](docs/USER_GUIDE.ja.md#10-datの加工履歴を確認する)

## 使い始める

1. ReleasesからアプリのZIPをダウンロードし、フォルダごと展開します。

2. `UltimateXIVBattleAnalyzer.exe`を起動します。

3. 「DAT読み込み」でDATを選びます。

4. 戦闘一覧を確認し、目的に応じて抽出・匿名化・保存を行います。

起動に必要な場合は [.NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) と [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) をインストールしてください。アプリは同梱ファイルを含むフォルダのまま使います。

操作ごとの手順は[画像付き操作ガイド](docs/USER_GUIDE.ja.md)にまとめています。匿名化したDATから人物を推測できる可能性は残ります。戦闘の動きや構成まで別物になる機能ではありません。また、DATの匿名化はACTログには適用されません。
